# @pipeworx/mcp-fmp

Financial Modeling Prep MCP pack backed by the stable FMP API.

## Auth

- Set `PLATFORM_FMP_KEY`, or pass `_apiKey` when calling a tool.

## Tools

- `profile`
- `quote`
- `quote_short`
- `historical_price`
- `intraday`
- `income_statement`
- `balance_sheet`
- `cash_flow`
- `ratios`
- `enterprise_value`
- `key_metrics`
- `financial_growth`
- `search_symbol`
- `search_name`
- `stock_screener`
- `stock_news`
- `earnings_calendar`
- `economic_calendar`
- `ipos_calendar`
- `mergers_acquisitions`
- `delisted_companies`
- `insider_trading`
- `institutional_ownership`
- `etf_holdings`
